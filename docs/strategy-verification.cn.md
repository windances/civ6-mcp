# 验证策略文档：以手册为先，手册沉默之处以游戏数据为准

三份策略文件（`docs/production-speed.md`、`docs/production-strategy.md`、
`docs/china-production-by-victory.md`）被逐条主张地审计。所采用的规则正是 `AGENTS.md` 所述的：
**手册是第一权威，手册沉默之处以已安装的游戏文件为准**——绝不是记忆，也绝不把仓库自己的教条
当作事实。四种判定：

- **手册**——手册如此陈述，并给出 `.tools/manuals/manual.clean.txt` 中的行号。
- **数据**——手册沉默；已安装的游戏文件如此陈述。
- **已修正**——该主张有误或不完整，修正在第 3 节。
- **教条**——没有任何来源如此陈述；它是仓库自己的策略，其价值仅与账本相当。

## 3. 本次核查中已修正或有保留的条目

1. **王朝更替的授予是有条件的，而且增益不会叠加。** 该能力的文本说"如果可用"
   （`Civilizations_Text.xml:296`），手册说增益不能叠加（`manual:2063`）。
   因此，在一个时代的科技与市政都已被增益之后才建成的奇观**什么都拿不到**——
   文档此前把它当成无条件的双重收益。已应用于 `china-production-by-victory.md`；这同样是
   028 的 `done when:` 坚持要把授予的增益 *写下来* 而不是假定的原因。
2. **长城是一条链，不是散点。** 文档暗示城墙无论立在哪里都给金币/文化/防御；
   数据要求**沿边境连成一线**，并且**按相邻段**付酬，这大大改变了长城计划的价值。
3. **宗教期限有一个手册数字。** 文档重复了预设的"大约一半的主要文明"；
   手册的权威是**"最多 7 个宗教"**，外加"尽量早点拿到一个"（`manual:1887`）
   以及工业时代开局的截止（`manual:2049`）。该预设的措辞现在被标注为教条。
4. **"使徒可以建造"是手册的松散说法。** `manual:1891` 说使徒"可以在任何有神庙的城市中
   **建造**"；数据则标记它们**只能以信仰购买**（`Units.xml:754-758`）。数据胜出，
   这一冲突记录在此，而不是被抹平。
5. **"金币购买是 2 倍"是一个数据值。** 手册只说金币可以购买单位和建筑
   （`manual:2111`）；2 倍乘数是 `GOLD_PURCHASE_MULTIPLIER`（`GlobalParameters.xml:334`）。
6. **增益百分比是按规则集而定的，本次审计的第一遍读错了。**
   2026-09-29 修正：该能力的描述被资料片*替换*
   （`Expansion2_Civilizations.xml:73` ->
   `LOC_TRAIT_CIVILIZATION_DYNASTIC_CYCLE_EXPANSION2_DESCRIPTION`），因此在风云变幻下——
   这些策略所针对的规则集——文本是 **50% 而非 40%**
   （`Expansion2_ConfigText.xml:543`），而不是基础游戏的**60% 而非 50%**
   （`Base\Assets\Text\en_US\Civilizations_Text.xml:296`，即此前一直被引用的那一行）。王朝更替的四个
   修正符是
   `MODIFIER_PLAYER_ADJUST_CIVIC_BOOST`、`..._TECHNOLOGY_BOOST`、
   `..._ADJUST_FREE_CIVIC_BOOST_WONDER_ERA` 和 `..._ADJUST_FREE_TECH_BOOST_WONDER_ERA`
   （`Civilizations.xml:269-289`）——由引擎实现，因此**任何数据文件中都不存在百分比**，
   读者不应指望能找到它。修正之后仍然成立的是那个*论证*：在两种规则集下差值都是 +10 点，
   所以中国的增益仍然比任何其他文明的都更值钱，跳过一个是浪费。不成立的则是任何建立在
   60% 之上的**算术**（它把每个增益高估了该物品成本的十个百分点）。
7. **分数获得了文档缺失的两个事实**：奇观的分数随**持有它的城市**移动
   （`manual:2405`），并且**被消灭的文明得零分**（`manual:2395`）——两者都使分数
   兜底策略的两条硬规则更明确。

  本文件中的核心数字（发电厂、鲁尔谷、贸易路线、购买乘数、宗教单位、神学压力、长城）
  每一条都直接重读过。

- 实时 **SQLite 数据库**是否会让埃塞俄比亚包的特使行覆盖基础/R&F 的行——
  加载顺序决定，只有运行中的游戏才能裁定。

**结论**：三份策略文档成立。有一条主张实质上不完整（奇观授予的条件），有一条含糊到会改变决定
（长城的摆放），有一条把预设的数字当作游戏的数字来重复（宗教期限），还有一句手册文字松散到
足以误导（使徒"建造"）。四条现均已记录，前两条已在
`docs/china-production-by-victory.md` 中修正。
