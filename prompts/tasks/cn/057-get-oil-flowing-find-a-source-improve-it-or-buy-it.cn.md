## 指令（逐字，2026-10-08）

「新任务：没有石油了，开采石油。」

石油是**战略资源、而且是存量**：池子读到 0，烧油的东西（现代装甲、机械化步兵、燃油电站）就不再能造、能升级、能补充。
人类报告说池子空了。动手之前先用游戏自己的资源行确认——`end_turn` 会打印它，`get_empire_resources` 会列出每个来源及其状态——
然后把一个来源弄进我们的账本。

## 按这个顺序找油

1. **`get_empire_resources`**——我们已知的每种战略资源、每个来源地块、以及它是否已被开发。石油显示为 `RESOURCE_OIL`；
   **一个未开发的来源是全游戏里最便宜的修补**。
2. **`get_strategic_map`**——把同一个问题放到全帝国：哪些石油地块在国境内且光着，哪些只在国境**外一圈**。
   **外一圈就是一次 `purchase_tile`（花金币）的距离**，通常比等国界自己长快得多。
3. 派人之前先 **`get_map_area`** 看清候选格——可能是丘陵、森林或丛林（要先 `remove_feature` 再 `improve`），
   也可能在别国境内，那就不是建造者的问题、而是贸易的问题。
4. 用 **`get_builder_tasks`** 找离每块地最近的建造者。**下单前查 `moves`**（本局 T434 实测：那一回合 4 次 `improve` 里
   3 次被 `CANNOT_IMPROVE|Builder has no moves remaining this turn` 打回）。**只给 `moves >= 1` 的下单**；
   若清单里最近的那个是 0，就取下一个——一次白下的指令浪费的是一个回合，不只是那次调用。

## 造什么

- **陆上石油**：建造者在资源格上建 **油井**（`IMPROVEMENT_OIL_WELL`）。需要：那块地、一个有次数的建造者、以及能开采石油的科技。
- **海上石油**：建造者到水域格上建海上设施；陆地单位没有 `TECH_SHIPBUILDING` 上不了水（实测："water tile - land units need
  Shipbuilding tech to embark"），所以要么用已经能下水的建造者，要么用城市自己的海岸格。
- **若没有一块是我们的、也买不到**：那石油就是个**贸易问题**——对有盈余的文明用 `get_trade_options(player_id)`，
  先 `propose_trade(..., mode="test")` 看对方还价，再 `send`。这是退路，不是第一步。

## 这件事的意义

结束时报告：**我们拿下了哪个来源、在哪一格、第几回合上线、之后池子读数是多少**——本任务要的是**正的石油收入**，
不是一个站在格子上的建造者。若这个窗口内无法转正，就说明**最接近完成的那个来源和第几回合能上线**，让下个窗口从那里开始。

## 完成条件

资源行里 `OIL` 显示为**正的每回合收入**（或存量不再下降），且我们至少有一块石油地被开发；
并记录下达指令的那个建造者与 `moves` 检查。达成后退役本文件。
