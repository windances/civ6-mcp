## 唯一变量：目标的防御

**攻城目标必须是一座真的有城墙的城市**——城墙池大于零，从攻击回执的 `walls: N/100` 或 `SIEGE PROGRESS` 块读出，不许假设。A2 的目标读作 `walls: none`，所以它的整个破墙阶段——攻城序列存在的理由——从未跑过；A3 就是要跑它。其余全部保持不变：

- 同一存档与设置（中国/秦始皇、王子、盘古小图、快速）；
- **修正后**的 `tactics/01`（这是 A2 之后唯一变化的东西，记录里必须写明：A3 与 A2 有**两处**不同——编成表、目标的防御——所以它的攻坚算术要与 A2 的 T68 对照着读）；
- 修正后的表就是现在的标准：**1 侦察**（Scout 或闲余骑兵）、**1 反骑兵**、siege 2、melee 2、ranged 4、cavalry 1，且**不购买撞车**（已拥有的才参战）。`tactics/07` 的 Gate 0 是"候选城市可见、且城墙/HP/驻军已读"——侦察单位就是让它成立的东西，而 A2 有 26 回合读不到。

## 按顺序做什么

1. **先侦察**（`tactics/07` Gate 0）。按修正后的表造出 Scout，用 `automate` 或明确移动派它向西、向西北，把它找到的每个城邦/对手城池都读一遍：`get_map_area` 看地块，第一次攻击估值或 `get_staging_plan` 看池子。Ancient Walls 出现在 Masonry 之后、要花产能——T70 还没起墙的城邦之后可能起，所以**已经看过的也要复读**。
2. **生产顺序按 `tactics/01`**：工程学落地时先下单 `UNIT_CATAPULT` 再谈任何经济建筑（H1 在 A2 的 T48 成立——这次是它的第二次检验，也是修正表下的第一次）。随军保留一个反骑兵单位：A2 的重战车问题就是无人能答。
3. **行军与集结按 `tactics/04`/`05`**：屏护在前、攻城在射程 2、最后填满开火格。`screen-the-siege` 与 `counter-the-cavalry` 是盯着这件事的规则；若变红，要么修队形，要么在日记里说明为何修不了。
4. **宣战**（`send_diplomatic_action`）——城邦现在走玩家操作，回执会写 `OK:WAR_REQUESTED`。宣战当回合站位，下一回合开火。
5. **能开火就每回合开火，并剪断供给线**——只要有一个相邻格在控制区外，城市每回合回血约二十点，所以富余单位去闭合环，弩炮干活。进度看 `SIEGE PROGRESS` 与**之后**的读取：攻击回执自己的伤害行是陈旧的，记录里已有三次误导案例。
6. **每十回合**：写 `ESTABLISHMENT:` / `WAR READY:` / `ENEMY SEEN:` 三行，并用数字回答 `10-TURN REVIEW` 的三个问题。
