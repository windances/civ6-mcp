游戏应当已经在运行，并且已经载入了一局对局。**绝对不要启动游戏，也绝对不要载入任何存档**：
启动和载入是人类的决定，正是它们让一个会话跑到别的分支上去（`0_MCP_NNNN` 的名字在不同回滚分支之间会
撞车），而载入会把另一个会话正在打的回合直接丢掉。你的第一件事只是**确认游戏现在能不能接受命令**。
能，就把这一局最多再推进 100 个回合，然后停下汇报。

**本文件是静态兜底。** 首选入口是 `scripts\resume-game.ps1`：它被动体检（`scripts\handoff.py`），
在没人能接手时打印出人类该做的那一步，并且在游戏已载入后**用体检出来的事实生成任务**（它核对过的回合
号、回合上限）再启动会话。只有在体检描述不了当前局面，或者人类直接把会话指向本文件时，才用它。也正因
为如此，这里不写回合号、不写存档名：那些东西一个回合就会过期。

0. **能力检查，只读。**按顺序两个调用：
   - `get_game_status` —— 它给出状态、当前回合，以及一行 `NEXT:`。
   - `get_game_overview` —— 一次真实读取。如果状态字符串说 `in_game`、但这次读取失败，那说明链路不可
     用，诚实的结论是"不能执行命令"。

   然后：
   - **`in_game`，且 overview 返回了回合号** —— 一切就位，按下面继续。
   - **其它任何情况 —— 停下并汇报。**不要启动、不要载入、不要循环重试。说清状态是什么、对人类意味着
     什么：
     * `not_running` —— 游戏没起来；需要启动，如果没载入对局还需要选一个存档。
     * `main_menu` / `leader_screen` —— 需要选一个存档并载入。`list_saves` 是可读的，你可以把最新的
       几个连同回合号报出来供人类挑选，**但不要自己去载入**。推荐要给到"能直接照做"的程度，因为人类
       马上就会按它行动：两个存档家族都要报——`0_MCP_NNNN` 和游戏自己的 `AutoSave_NNNN`——各自带上
       回合号，并且**任何回滚之后优先选最新的 `AutoSave`**，因为 `0_MCP_NNNN` 的名字在不同回滚分支
       之间会撞车，同一个名字可能是完全不同的局面。如果某个存档到底停在哪一回合有疑问，
       `scripts\turn-of-save.py "<path>"` 可以在任何东西被载入**之前**把回合号打出来。
     * `tuner_busy` —— FireTuner 只允许一个连接，已被别的进程占着（报告里会带 pid）。等下去没用：
       要么人类用 `scripts\civ6-clean.ps1` 停掉那个进程，要么继续在那个会话里打。
     * 游戏在屏幕上但 FireTuner 不响应（"Is the game running with EnableTuner=1?"）—— 这局是在 MCP
       之外启动的，从这里任何调用都够不到它。如实汇报；修法是一次重启并载入，那同样是人类的决定。

   有一种已知故障**不算**"不能执行命令"：`get_units` 报所有单位 0 移动力（"the turn's movement points
   were never granted"）。复读一次；如果仍然如此，**照样结束回合**（下一回合会恢复满移动力），不要重
   启游戏。

1. 这是上下文为空的新会话。先调 `get_diary` 读你自己留下的历史——意图、计划、判断——但**局面一律以游
   戏为准，不要用日记里的数字**。然后用**一次**读取把全部事实重建出来：

   ```
   .venv\Scripts\python.exe scripts\orient.py --radius 2
   ```

   它在同一条连接上打印：总览、部队、城市、科技/市政、政策、外交、资源、总督、商路、建造者任务、城
   邦、胜利/人口统计、宗教、伟人、万神殿与通知。要按城市与部队周边的地图来做计划时加 `--maps`，想收
   窄用 `--only a,b`，某个字段真的存疑时用 `--full`。**不要自己手敲这份清单**：把一次重新定位拆成十
   来次独立读取，总会漏掉其中一次，这个脚本就是为此存在的。如果它回答 `could not connect to
   FireTuner`，那就是第 0 步的失败情形——停下汇报，不要循环重试。

   还有三个它**不**打印的通道，而这三个都会卡住回合：`get_pending_diplomacy`（AI 主动发起的外交会话
   会阻塞推进——用 `respond_to_diplomacy` 应答）、`get_pending_trades`（`respond_to_trade`）、以及
   `get_world_congress`（**世界议会在 `end_turn` 内部同步触发**，所以任何投票都必须先用
   `queue_wc_votes` 排队）。

2. **规划之前先读临时任务**：`prompts/tasks/tmp/` 下每一个 `*.md`（不读 `README.md`，不读
   `current_tasks.md`，不读 `done/`）。那些文件是**在效指令**，各自带有 `done when:`、`overrides:`、
   `expires:`，而循环里没有别的东西知道它们存在。`current_tasks.md` 是当前在效任务的登记表，
   `docs/task-history.md` 记录已退役任务测到了什么。已完成或已过期的任务，通过把它移进 `done/`
   并在文件名里带上回合号来退役。

3. 查完再决定，然后按回合循环推进：`get_game_overview` → 清掉 `end_turn` 报出的阻塞项 → 给每一支部队
   下令 → 设定城市生产 → `end_turn`。**报失败的变更之后要复核局面**——被拒绝的指令也可能已经生效
   （实测：一条商路回答了 `NO_MOVES`，但路线已经建立、鼓舞也已经触发）。

4. 使用 civ6-orchestrator skill 及其中写好的策略指令（含总督与大将军的用法）。

结束时汇报：起始回合与最终回合、城市数、人口、科技/文化/金币、军力、建了什么、打过哪些仗，以及遇到的
所有阻碍（工具报错、挂起、恢复），都带上回合号。
