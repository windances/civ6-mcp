用 civ6-orchestrator skill 及其中写好的策略指令执行一次**清剿行动**：把最近的蛮族营地当作战前分析
目标，按我们的战争策略把它消灭。

0. 先调 get_game_status 确认状态，不要靠猜。
   - in_game（并给出当前回合）：直接继续。不要启动游戏，也不要载入任何存档。
   - not_running：launch_game 并等它启动完成，再回到这一条。
   - main_menu / leader_screen：list_saves 取最新的一项（不要只认 0_MCP_ 前缀，游戏自己的
     AutoSave_ 往往更新），load_game_save 载入并核对回合号。
   - tuner_busy：FireTuner 只允许一个连接，已经被别的进程占着（它会报 pid）。**停下并报告**，
     不要启动第二个游戏，也不要反复重试。

1. 这是**清剿**，不是全面战争：不要对任何文明或城邦宣战，不要碰蛮族营地以外的目标，不要因为这次
   行动改变既定的发展计划（研究、市政、区划、Builder 任务都照旧推进）。

2. 先做完整的战前分析，用 `prompts/tactics/07-pre-war-analysis.md` 的 **camp gates**，并把六道门
   按名字写进日记：`CAMP / GUARD / FORCE / GROUND / WORTH / HOLD / CONVERT / GO`。要点：
   - **营地没有 HP、没有城墙**：一个军事单位**移动**到营地格即清除它（和占城一样是"走进去"，不是
     攻击）。攻击会耗尽移动力，所以最后一击必须是"移动"。
   - **危险的是守卫**：数清营地 2 格内**每一个**蛮族单位的类型/CS/HP；缺数据就报缺失，不要猜。
   - **两个攻击者 + 克制兵种**：蛮族**枪兵是 anti-cavalry，骑兵是错的**；用远程（不吃反击）先削，
     再由近战**未消耗**的单位走进营地格。绝不用侦察兵/Builder/商队去营地（平民会被抓）。
   - **最后一格**：进场必须从"上一回合已经占住"的相邻格出发（ZOC 与 2 费地形都会吃掉整回合）。
   - **动手前**报出"贴着我方近战、值得人类用三十六计转化"的蛮族单位，让人类先从游戏 UI 转化；
     然后照样把营地清掉，不要为了留着转化而放过它。
   - 记下它**已经产出过什么**（worth），并说清哪座城市因此暂时少了驻军（hold）。

3. 兵力不够就补，且按策略补：优先远程（有 `斯巴达教育 Agoge` 就用），金币 >300 且没有点名用途时
   直接买（`buy`/`purchase_item`），不要为了这次清剿动用到前线的攻城车。

4. 按回合推进：每回合 `get_game_overview` → 处理 `end_turn` 报出的阻塞项 → 给**每一支部队**下令 →
   城市生产 → `end_turn`。战斗规则照 `tactics/02`（接敌）、`03`（被打）、`05`（站位）、`06`（火力）
   执行；同一个目标不要一个一个送（`mass-on-contact` 要求 2-3 个攻击者）。

5. 清剿完成后恢复原来的发展节奏，并在结束时汇报：清掉的是哪个营地（坐标）、第几回合完成、投入了
   哪些单位、付出了什么代价（掉血 / 金币 / 耽误的生产）、还知道哪些营地未清；以及那六道门在日记里的
   实际答案，和本次遇到的任何阻碍（工具报错、阻塞、恢复）都要带回合号。
